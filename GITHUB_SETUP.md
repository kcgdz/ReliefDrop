## Publish

1. Create the repository on GitHub and upload the project files, including `assets/`, `studio.css` and `i18n.js`.
2. In Settings → Pages, deploy your main branch from the root folder.
3. Once Pages is live, add its URL to the repository Website field and the top of README.md.
4. Use the description and topics above in the About section.
5. For a social preview, export `assets/banner.svg` to a 1280 × 640 PNG and upload it in Settings → General → Social preview.
